# Portfolio Plan

## Goal
Build a responsive, professional personal-branding website for Abdullah Mohamed that works as:

1. A portfolio for selected shipped work.
2. A reference page for potential freelance and product clients.
3. A clear contact and conversion page for leads.

## Visual Direction

- Gold theme from the README.
- Dark graphite base with warm gold accents.
- Premium but restrained layout.
- Responsive first, with a strong desktop presentation and a clean mobile flow.

## Site Structure

1. Hero with positioning, CTAs, and quick stats.
2. Selected work section with screenshots and featured projects.
3. Service / plan cards for freelance inquiries.
4. Experience timeline.
5. Technology stack and contact actions.
